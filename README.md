# PIEC Next Premium — V4

A restrained, editorial conservation landing page for the People’s Initiative for Environmental Conservation.

## V4 refinement
- Simplified the opening Western Ghats reveal to a primary ridge + subtle secondary contour.
- Removed decorative intro stars, points, halo, grain, and redundant ridge layers.
- Tightened intro timing and title choreography.
- Rebalanced hero typography and CTA sizing instead of globally enlarging everything.
- Kept the existing responsive navigation, section structure, and data-driven content model.
- Kept motion restrained and preserved reduced-motion support.

npm install
npm run dev
